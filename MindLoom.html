Shared map

Several people work on one map file at the same time.

What it does

About every 15 seconds, and whenever you save, MindLoom reads the file, merges in what the others have changed, then writes the result back. Nobody’s changes are overwritten, and the Activity panel shows who changed what.

What you need

Save the file in a shared location that is replicated between everyone, such as a OneDrive or SharePoint folder synced to your computer (Dropbox works too). Everyone then opens that same file.

A file kept only on your own computer, or on a drive that does not sync, will not be shared with anyone.

Use Chrome or Edge, and set your name under Settings so changes are signed.

Optional extras, off until you want them: dependencies and application mapping, Coverage, RACI, baselines, comments and history. See Settings and View.

  • Double-click the canvas to add a node there. Right-click a node for its menu.
  • Scroll to zoom, drag to pan, press F to fit everything.
  • Press Q to capture a task. Add #tag, @owner and a date such as fri or +2w, then Enter. It lands under an Inbox node.
  • Shift+click to select several nodes and change them together. Ctrl+drag a node onto another to move it.
  • Double-click a colour on the colour bar to rename it.
  • Each visit opens a fresh map. Use File > Save to keep a file copy. Your last map is under File > Restore backup.
  • Touch: drag to move or pan, pinch to zoom, long-press for the menu.

Saved views
A view remembers filters, hidden trees, collapsed branches, completed and date-axis settings, and where you were looking.
Export presets
A preset remembers the Date Axis on/off, Slide view, Critical path only, Lines, Bar Colours, Lane Bands, Show Undated, Hide Completed, the background and the image format. Click a preset to export with those settings; your screen is put back as it was. Presets are saved in your file.
Baselines
A baseline is a copy of every start and due date at one moment. The Date Axis then draws a dashed ghost where each bar was planned, with the slip in days. It is saved in your file.
