MindPlanner

Version 1.19.0

A fully offline, single-file tool for mind mapping and planning: dependencies, a board, a timeline and status reports, all from one map. No cloud services, no dependencies, no install — just save the HTML file and open it in any browser.

Created by Chris Healey, built with assistance from Claude (Anthropic).

Demo data

Loads a made-up map for demonstrations. Dates are set relative to today, so overdue and due-today flags always show. Your current map is backed up first (File > Restore backup) and Undo brings it back.

Features

Multiple root nodes · Colour categories · Cross-links with labels · Node notes, project, owner & status fields · Tags · Filter bar · Search · Auto layout · Minimap · Undo/redo · PNG, Markdown & CSV export · JSON save/load · CSV & Markdown import · Customisable background · Snap to grid · Multi-select & bulk ops · Reparent by Ctrl+drag · Focus roots · Statistics dashboard · Bookmarks · Presentation mode · Dark/Light theme · Node timestamps · Duplicate subtree · Hide completed · Due dates with overdue flags, an Agenda view and a draggable Timeline (Gantt) view · Clickable links in notes · Tidy tree layouts · Bulk date shift for a branch and its links · Copy, cut and paste branches (also between maps, or paste plain text as nodes) · Saved views · Dependencies (prerequisite arrows and a waiting badge) · Board (kanban) view · Status report you can copy, download or print · Command palette (Ctrl+K) that finds every action · Save indicator, optional auto-save to your file and rolling backups · Touch support · Print support · Keyboard-driven workflow

Tips

• Double-click the canvas to add a node at that spot
• Right-click any node for a context menu
• Scroll to zoom, drag canvas to pan
• Blue dot means the node has metadata or notes
• Status icons appear top-right on nodes
• Tags are comma-separated — press Enter to add
• Data auto-saves to browser localStorage
• Use Save JSON to back up or move between machines
• Shift+click to multi-select, then bulk-change colour, status or owner
• Ctrl+drag a node onto another to reparent it
• Use Focus to show/hide entire root trees
• Collapse All / Expand All in the View menu
• Snap to Grid in View for tidy alignment
• Import CSV or Markdown from File > Import
• Right-click a node to bookmark or duplicate subtree
• Press P for presentation mode (arrows to navigate)
• Toggle dark/light theme from the View menu
• Set a due date in the details panel (press I); overdue and due-today nodes are flagged and counted in the toolbar
• Touch: drag to move or pan, pinch to zoom, long-press for the menu, double-tap to edit or add
