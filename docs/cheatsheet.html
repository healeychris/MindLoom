Map it

Branches, cross-links, colours and tidy layouts.

  • Tab adds a child, Enter a sibling, F2 renames
  • Double-click empty canvas to add a node there
  • L then click another node to cross-link
  • Tidy menu: horizontal, vertical, balanced, outline
  • Ctrl+drag onto a node to move a branch under it
  • Double-click a colour on the colour bar to rename it

Track it

Status, owner, tags and dates on any node.

  • I opens details: status, owner, project, tags, notes
  • Start and Due dates; overdue items are flagged in the toolbar
  • Checklist, % progress and repeat (weekly, monthly…)
  • Shift+click several nodes, then change them together
  • Ctrl+F filters by status, owner, tag or due

See it your way

The same map as a list, a plan or a report.

  • A Agenda: overdue, today, this week
  • T Timeline: drag bars to change dates
  • Date Axis: swimlanes, milestones, critical path, Slide view
  • K Board (kanban) · R status Report
  • V Saved views keep filters, folds and zoom

Start fast

Ready-made maps and quick ways in.

  • The start screen offers templates: roadmap, risks, RACI, workshop…
  • The map type chip (Plan, Mind map…) tidies the toolbar
  • Q Quick capture adds a task to the Inbox (see right)
  • Ctrl+K finds any command by name
  • Workshop mode: sticky notes you file onto themes

Share it

Pictures, files and shared maps.

  • File › Export: PNG, SVG, CSV or Markdown
  • Date Axis + Slide view + PNG for clean PowerPoint slides
  • Report: copy, download or print a status summary
  • File › Import › Merge from file joins two copies
  • File › Shared map: one file in a OneDrive folder (Edge, Chrome)

Keep it safe

One HTML file. Nothing leaves your machine.

  • Ctrl+S saves a .json file: the only format that keeps everything
  • After the first save, auto-save keeps that file up to date
  • Ctrl+Z undoes up to 50 steps; deletes offer Undo
  • File › Restore backup has earlier copies
  • Drop a .json file on the window to open it

Quick capture (Q)

Book venue #event @Sam fri
  • #tag adds a tag, @name sets the owner
  • End with a date: today, tomorrow, fri, +2w, 14/12
  • Enter adds it under Inbox and keeps the box open

Good habits

  • Each visit opens on the start screen. Pick Continue last session to carry on; in Edge and Chrome it reconnects your file
  • Keep maps in a synced folder so they are backed up
  • Settings › Simple Menus hides the specialist items
  • Right-click a node for its menu; long-press on touch
